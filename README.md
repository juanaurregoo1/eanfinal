Proyecto Final – Excel e Inteligencia Artificial EAN
Descripción del proyecto
Este proyecto fue desarrollado como parte del módulo 3 de Excel e Inteligencia Artificial de la Universidad EAN.
El objetivo principal es organizar y analizar información financiera mediante herramientas de Excel, utilizando fórmulas automáticas, tablas y gráficos que permitan interpretar los datos de manera más sencilla.
Objetivos
- Organizar información financiera de forma clara.
- Aplicar fórmulas de Excel para automatizar cálculos.
- Analizar ingresos, gastos y resultados financieros.
- Crear un dashboard para visualizar la información.
- Utilizar inteligencia artificial como apoyo en el desarrollo del proyecto.
Herramientas utilizadas
- Microsoft Excel.
- Fórmulas y funciones de Excel.
- Tablas y gráficos.
- Dashboard con selector de mes.
- ChatGPT como herramienta de inteligencia artificial.
- GitHub para almacenar y presentar el proyecto.
Desarrollo del proyecto
Primero, se organizó la información financiera en diferentes hojas de Excel.
Después, se utilizaron fórmulas para realizar cálculos automáticos y facilitar el análisis de los datos.
Posteriormente, se creó un dashboard que permite visualizar los principales indicadores financieros, como ingresos, gastos y saldos, mediante gráficos comparativos.
El dashboard también permite seleccionar diferentes meses para consultar los resultados.
Uso de inteligencia artificial
Durante el desarrollo del proyecto se utilizó ChatGPT como herramienta de apoyo para comprender fórmulas, organizar la información, estructurar el dashboard y mejorar la presentación de los resultados.
La inteligencia artificial permitió facilitar algunas actividades y resolver dudas relacionadas con Excel.
Resultados
El proyecto permitió organizar la información financiera, automatizar cálculos y presentar los resultados mediante un tablero visual.
Esto facilita la comparación de los datos y permite comprender mejor el comportamiento financiero de los periodos analizados.
Archivos del proyecto
- PROYECTO_FINAL_EAN_FINANZAS_DASHBOARD.xlsx: archivo de Excel con las tablas, fórmulas y dashboard.
- INFORME_PROYECTO_FINAL_EAN.docx: documento explicativo del desarrollo del proyecto.
- README.md: descripción general del proyecto.
Conclusión
Este proyecto permitió fortalecer mis conocimientos en Excel y comprender cómo la inteligencia artificial puede apoyar el análisis de información.
También pude identificar la importancia de estas herramientas en mi carrera de Mercadeo y Estrategia Comercial, especialmente para analizar resultados y apoyar la toma de decisiones.
